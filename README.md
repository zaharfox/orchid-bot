# 🌸 OrchidBot — Telegram-бот для любителей орхидей

Telegram-бот для ведения коллекции орхидей, напоминаний об уходе и получения полезной информации о растениях.

## Функции

- 🌺 **Коллекция орхидей** — добавляйте, просматривайте и удаляйте свои растения
- 💧 **Трекер ухода** — отмечайте полив, подкормку и пересадку
- 🔔 **Умные уведомления** — бот напоминает, когда пора поливать или подкармливать
- 📚 **Энциклопедия** — подробная информация о 6 популярных видах орхидей
- 💡 **Советы по уходу** — полив, освещение, подкормка, пересадка
- 🎲 **Интересные факты** — узнайте что-то новое каждый день

## Поддерживаемые виды

| Вид | Особенности |
|-----|-------------|
| 🌸 Phalaenopsis | Самый популярный, неприхотливый |
| 🌺 Dendrobium | Любит прохладный период покоя |
| 💜 Cattleya | «Королева орхидей», ароматная |
| 💛 Oncidium | «Танцующая кукла», неприхотливый |
| 🌼 Miltonia | «Анютины глазки», любит прохладу |
| 🔵 Vanda | Экзотическая, с воздушными корнями |

## Установка и запуск

### 1. Получить токен бота

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/newbot`
3. Следуйте инструкциям и сохраните полученный токен

### 2. Клонировать / распаковать проект

```bash
cd orchid_bot
```

### 3. Создать виртуальное окружение

```bash
python -m venv venv

# Windows
venv\Scripts\activate

# Linux/macOS
source venv/bin/activate
```

### 4. Установить зависимости

```bash
pip install -r requirements.txt
```

### 5. Настроить переменные окружения

```bash
# Скопировать пример
cp .env.example .env

# Открыть .env и вставить свой токен
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
```

### 6. Запустить бота

```bash
python bot.py
```

## Технологии

- **Python 3.10+**
- **aiogram 3.x** — асинхронный Telegram Bot API
- **aiosqlite** — асинхронная работа с SQLite
- **APScheduler** — планировщик задач для уведомлений
- **python-dotenv** — управление переменными окружения

## Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Запуск и главное меню |
| `/help` | Справка |
| `/myorchids` | Моя коллекция |
| `/add` | Добавить орхидею |
| `/fact` | Случайный факт |

## Как это работает

1. Пользователь добавляет орхидею, указывая её вид
2. Бот устанавливает интервал полива и подкормки по умолчанию для этого вида
3. Пользователь отмечает уход нажатием кнопки
4. Каждый день в установленное время бот проверяет, какие орхидеи нуждаются в уходе
5. При необходимости бот отправляет напоминание
